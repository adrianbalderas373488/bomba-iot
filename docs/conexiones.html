RX2 es el GPIO16, el que usa el código para los LEDs. En algunas placas viene impreso como G16 o 16. Si tu placa tiene 38 pines, cambia el número desde arriba pero no el texto: guíate por el texto.

Antes de conectar el USB

  • Ningún cable va de 3V3 o VIN directo a GND.
  • Hay solo un cable en cada hueco.
  • Si el riel de tu protoboard está cortado a la mitad (una línea interrumpida), usa la mitad de arriba o pon un puente.
  • Prueba el buzzer: conectado directo a 3V3 y GND debe sonar solo. Si no suena, es pasivo y no sirve con este código.
